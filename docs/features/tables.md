# Tables

Cells are nodes: a table is a container block carrying the `table` class — a node classed `table` whose child blocks are the rows, and each row's child blocks are the cells. The grid is a render projection of its subtree — the whiteboard pattern one level down ([whiteboards.md](whiteboards.md)); the `/table` scaffold is part of the slash commands ([outliner.md](outliner.md#slash-commands)).

- **Every cell is an ordinary node** — own UUID, full content grammar, backlinks, search indexing, classing, properties, the focused view. Mention it anywhere (`@` finds it; the reference renders the cell's *current* content — there is no separate "table content" that links can't reach), class it, give it properties, zoom into it from its bullet; the same children render as a grid, an outline, or focused, because they are the same nodes.
- **The grid is a view, not a type.** The container's children render as a CSS grid: the column template comes from the first row's cell count; rows align by subgrid, so a ragged row shows a blank (fewer cells) or spills an extra column (more). Underneath, the tree is an ordinary outliner tree — Tab/Enter, drag, and the keyboard contract work inside cells unchanged (Enter splits, Tab indents); cells edit inline through the standard block editor (the usual debounced save).
- **Structure changes are ordinary creates.** `/table` scaffolds the table under the current block at the caret: one row of three empty cells, caret in the first cell; the typed argument sets the column count (`/table 5`). Hover the table: **+ Row** appends a full row, **+ Column** appends a cell to every row. **− Row / − Column** delete the last row / the right-most column (inline-confirm: the check deletes, the × cancels; a deleted row's cells ride the ordinary subtree trash). No new op, no wire token — every write is an `object.create` on ordinary nodes.
- **Read-only projections** (embeds, the presentation deck, the Child pages tree) render the same grid — the deck routes table-classed blocks through the same BlockRow grid branch, no flattening; editing stays in the outline.
- **Export** rides the table toolbar's **…** menu — CSV/xlsx of the current view and the Import table… round-trip are [exporting.md](exporting.md)'s.
