# The outliner

Notees is a Logseq-style outliner: bullet points, and each bullet is a block is a node. This page is the editor's full contract — the gesture table, the slash commands, the task toggle, and the long interaction rulings (collapse, multi-select, drag reorder, the condensed layer). What a block becomes (a page, a list item's number, a divider) lives in [pages.md](pages.md); what a block can carry (mentions, chips, typed-link marks, assets) lives in [links.md](links.md).

## The core contract

| Gesture | Effect |
|---|---|
| `Enter` mid-text | **Splits the block at the caret** — the head stays, the tail moves to a new block right after: a **sibling** normally, the **first child** when the block has children (they stay with the head). A selected range is **cut first** — the split lands at its start. |
| `Enter` at the start | A new empty block **before** this one. |
| `Enter` at the end | A sibling after — unless the block has children, in which case the new block becomes their **first child**. |
| `Shift+Enter` | A `hard_break` — a line jump *inside* the block. The only break token in the grammar. |
| `Backspace` at the start of text | **Merges this block into the previous one** (previous sibling, or the parent when this is an only child — otherwise nothing). The unflushed draft rides along. |
| `Backspace` on an empty block with children | The children are **promoted** into the block's place, then the block is deleted. |
| `Delete` at the end | Merges a childless next sibling into this block; with **no next sibling**, an **only child** merges into this block instead (its children move up into its place). Otherwise nothing. |
| Indent / outdent | `Tab` indents under the previous sibling; `Shift+Tab` outdents to the grandparent right after its parent. The outdent **behavior setting** (Settings → Editor) chooses Direct (only the block moves) or Logical (default — subsequent siblings follow under the outdented block, preserving category grouping). Neither leaves edit mode — the caret hands back to the moved block at the same offset. |
| `↑` / `↓` | Move within the text **by line** (the browser default); on the **first/last visual line** the edit session hands to the block **above/below** in visible document order (folded subtrees contribute no rows). `↑` on the first top-level block hands the caret **to the page title**; `↓` on the title enters the first block. |
| `→` at the end / `←` at the start | The edit session hands to the **next / previous** visible block (caret at the start / end). On the title, `→` at the end enters the first block; `←` at its start is a no-op. |
| Drag | Reorders among siblings (fractional positions + TreeCrdt — proven machinery, ported). |
| Collapse / expand | View state only; children stay first-class nodes. Honored in **every** mode — prose included: folded subtrees hide, the chevron start-anchors the prose row (hover-revealed, **persistent at rest while collapsed** — the persistent chevron IS the collapsed indicator), and the fold chords act on the same state. |
| Prose mode | Bullets hidden, indents flattened — a **view transform, not content**. Collapse is honored exactly as in outline (folded subtrees hide, chevron + persistent collapsed indicator, the same fold chords); only the indent-line fold gesture stays outline-only (prose has no indent line). |
| `Ctrl/Cmd+C` with no selection | Copies that block's node link (`<origin>/<uuid>`) — same in a page title. With a text selection, the browser's text copy runs as usual. |
| `Ctrl/Cmd+V` holding a node link | Pastes the link as a **mention** at the caret (the page title too — the header title edits with the full block editor) instead of raw text; any other clipboard text pastes normally. Both directions toast a confirmation. |
| `Ctrl/Cmd+V` holding **multi-line** text | **Splits at the caret into sibling blocks** — the head keeps the text before the caret plus the first pasted line, each further line becomes its own block right after, and the last line absorbs the tail (the caret lands at the start of that tail). Trailing blank lines from the copy are dropped, not minted as empty blocks; a paste with a single visual line, the page title, code blocks, and text-property values keep the plain-text default (`hard_break`s inside the block). |
| `@` with a selection | The selection survives: the node picker opens **with the selected text as its search query**, and confirming (or creating) replaces the selection with the link — a faint **"Replacing selection with link"** banner above the field names the mode. `Ctrl/Cmd+Enter` on a row inserts the link with the selected text kept as a custom label; Esc hands the selection back untouched. **Ctrl/Cmd+L is the same gesture** (the picker opens whenever a **non-word character** — whitespace, punctuation, or the start of the text — precedes the selection; a letter, digit, or underscore means the email case, no popup — the typed-`@` rule). |
| `Ctrl/Cmd+Shift+L` with a selection | The picker opens with an **empty search query** and the banner **'Link with custom label "…"'**: whatever you pick (or create) replaces the selection with a link **labeled with the selected text** — the search never feeds the label. Opens anywhere a selection exists, no boundary rule. |
| Right-click a node link | A context menu: **Open** / **Open in sidebar**, **Edit link…** (retarget the link, set or edit an optional custom label), **Remove link** (unlink, keeping the text — or the custom label when one is set), **Delete link** (removes the link from the block entirely). |
| Right-click a block → **List style ›** | The bullet becomes a **numbered** (`1.`), **alphabetical** (`a.`), or **roman** (`i.`) marker — **Bullet** returns to the dot. The number is never stored: it derives at render time from the contiguous run of same-style siblings above the block (any other sibling resets the count), so renumbering is automatic and nested lists number independently. |
| `/hr` (the **Divider** command) | **Inserts a horizontal rule** — a new block whose content is exactly `---`, rendered as a line at display time (the block stays an ordinary citizen: click it to edit the raw dashes, typing anything else turns it back into prose, Backspace from the next block deletes it). Children nested under a rule never render — a rule terminates a section. The full ruling is [pages.md](pages.md#dividing-a-page)'s. |
| `Alt+Shift+↑` / `↓` in a block | **Moves the block** among its siblings — reorder without dragging. One move per press; the caret stays put. |
| `Ctrl+.` on a block, `Ctrl+Alt+←` / `→` | **Fold / unfold the focused block's subtree** (session view state). `Ctrl+.` toggles; the Ctrl+Alt chords go one direction each. (Alt+←/→ are Back/Forward — [search.md](search.md#global-chords).) |
| `Shift+click` / `Ctrl+click` a block row, or drag over rows | **Multi-select** blocks. Shift+click extends a range from the anchor, Ctrl/Cmd+click toggles one row, press-and-drag arches over rows. **The selection law:** text selection exists only inside the block being edited — read-mode content is unselectable, and a press-and-drag arms the block range only when the pointer **exits the pressed block's borders** (a drag starting inside an editing block keeps its in-block text selection until the same border exit, then hands over to the block range). **The selection is whole-subtree** — selecting a block selects its children — **and level-capped at its shallowest depth**: every write maps the raw rows to their ancestors at the stack's min depth, so the stack never mixes a block with a descendant of its sibling (extending a range onto a child selects its parent instead; toggling inside an already-selected subtree is a no-op; the stored stack is the capped roots — the set the block drag moves). The selection reads as **one card per contiguous run**: a soft accent-tinted underlay (the selection wears the active accent color, like every engagement surface) **behind the rows** (the text on top stays fully readable), spanning the run's block elements — first row's top to last row's bottom, shallowest left edge to deepest right edge. Selection and edit mode are mutually exclusive: whichever block is editing hands back to read mode the moment a selection forms (a modifier click, a drag-select), and one plain click on another block both clears the selection and enters edit mode there. A floating action bar offers the group ops — bulk class assign/unassign, bulk tag, bulk move to a page, bulk delete (confirmed) — one write per block. Esc or clicking elsewhere clears. |
| Click the muted "+ Add block" row at the page's end (always present) | The **ghost block** (the original behavior, refined): the page root trails exactly one muted "+ Add block" row as the last sibling of the main level — including on an empty body; display-only until the click, which creates a real empty block at the end and focuses it. It is the sole add affordance (no separate add button), and its bullet reads faint — never at a real bullet's weight. In prose mode it stays, bullet hidden like every prose bullet; in cards mode the grid's last cell is a dashed **ghost card** ("+ Add card") — the same click realizes a new card. System sections (Backlinks, Unlinked mentions, property values) never trail a ghost — their add flow is the section's own "+", not a per-item editing affordance. |
| `Alt+←` / `Alt+→` | **Back / Forward** through the pages you opened — the app's own history stack, the same one deep links ride. |
| `Ctrl/Cmd+N`, `Ctrl/Cmd+,`, `Ctrl/Cmd+\` | **New page** (created and opened), **Settings** (the full settings page, deep-linkable at `/settings/<section>`; the quick-tweaks modal retired — the palette's **Toggle theme** command covers the one-gesture flip), **toggle the sidebar**. Every global chord yields to text fields. |

Long-form writing emerges from nesting bullets, not from a document mode. That is a deliberate bet — the confident statement is: structure you got for free beats structure you typed as metadata.

Blocks are first-class storage but second-class display. Display defaults keep them quiet: backlinks aggregate mentions per containing page ([links.md](links.md)), search ranks page-title literal matches ahead of block hits (with block hits labeled by their containing page — the sidebar search field and the palette's Content section, [search.md](search.md)), and queries default to root scope. When a bullet matters enough to stand alone, you promote it — see [pages.md](pages.md#promotion-and-demotion).

**Assets are content.** An `asset_ref` token in a block renders instead of merely naming the file: image-like bytes show an inline preview (click opens the fullscreen lightbox, with download), anything else a filename-and-size chip (click downloads). A block whose entire content is one asset renders it full-bleed. The bytes ride the content-addressed asset store; a reference whose asset no longer exists shows a dashed placeholder with the raw id — never a silent hole.

## Slash commands

`/` in a block offers the block actions (text, quote, task, line break, URL, code, divider) plus the live ones: **`/code …`** converts the block to a code block (the sentence you wrote becomes the code; the typed argument is the language hint — `/code python`), **`/query`** inserts a query block and opens its builder ([queries.md](queries.md)), **`/date …`** links a typed date to its journal page (created on demand; a bare `/date` — or an unparseable remainder — opens the calendar popup at the caret and the picked day links on commit, [calendar.md](calendar.md)), **`/template …`** instantiates a template at the caret (see [templates.md](templates.md)), **`/table …`** inserts a table whose cells are ordinary linkable blocks (see [tables.md](tables.md)). Commands filter on the first word — the rest is the command's argument. Beyond the menu, **Ctrl/Cmd+Enter** on a block toggles its task state: a plain block becomes a task set to **Pending**, an open task jumps straight to **Done**, and a **Done** (or Cancelled) task clears back to a plain block — the task semantics are [tasks.md](tasks.md)'s.

## Styling a block as a list item

A block's context menu → **List style ›** turns the bullet into a **numbered** (`1.`), **alphabetical** (`a.`), or **roman** (`i.`) marker; **Bullet** returns to the dot. The number is derived, never stored: it counts the contiguous run of same-style siblings above the block (any other sibling resets it), so inserting or reordering items renumbers automatically and nested lists number on their own.

## The editor — the long rulings

The full outliner interaction set, beyond the table:

**Text core** — typing with debounced saves, the editable filling the row so clicking anywhere places the caret, Enter placing a new sibling right after the current block, Shift+Enter hard breaks, Backspace delete, Tab / Shift+Tab reparenting via `object.move` with fractional sibling-midpoint ordering; the editing block's bullet carries the accent highlight — the engaged-row signal at a glance; and while a block is in edit mode, the **edit thread** lights the path from the top-level block down to the caret — a separate measured overlay draws one line from the top ancestor's bullet, down its column, taking a rounded turn to the right at each level change, ending at the editing block's dot (the tree's own indent rails stay resting, ride the bullet's center column, and pass under the thread where the columns coincide; outline mode only — prose flattens the indents; a top-level edit lights nothing); the editing block's own bullet highlight never spills to its children, and the ancestors' collapse chevrons stay hidden.

**Marks editing** — structural edits preserve untouched runs; selection toolbar + Ctrl/Cmd+B/I/Shift:X + `**`-wrap.

**Node-link clipboard** — Ctrl/Cmd+C on a block or page title with no selection copies `<origin>/<uuid>`; pasting that link — or a bare uuid — splices a mention at the caret, both with a toast confirmation.

**Link authoring from selection** — typing `@` over selected text — or **Ctrl/Cmd+L** — opens the picker with that text as the query; the pick replaces the selection, Ctrl/Cmd+Enter keeps it as a custom label; **Ctrl/Cmd+Shift+L** opens with an empty query and keeps the selection as the label instead, under a faint mode banner. The picker contracts are [links.md](links.md)'s.

**Node-link context menu** — right-click a link: edit destination + custom label, remove the link keeping the text, or delete it outright.

**Code blocks** — `/code` converts the block — the sentence you wrote becomes the code, the typed argument is the language hint; a code block edits in place through a CodeTextarea surface: the language badge stays, typing writes the token's text on the standard debounced path, Esc/blur hands back to read mode.

**Collapse** — chevron per block, hidden at rest and revealed hovering the bullet gutter — resting rows stay clean; DEVICE-PERSISTED per page — the folds survive reloads (localStorage, never an op) — plus the v1 gesture, individually folded: the vertical indent line under a block is itself a control — it reaches from the block's bullet down across its metadata sections to the last child, and one click anywhere on it folds EACH direct child individually (the owner's own expansion stays; the children rows remain, their subtrees fold at once; when every child is folded, the click unfolds them all), and the `Ctrl+.` / `Ctrl+Alt+←/→` fold chords on the focused block.

**Block multi-selection** — shift+click range, Ctrl/Cmd+click toggle, drag-over rows — the drag arms when the pointer exits the pressed block's borders, never a text selection: read-mode content is unselectable by law; the set is whole-subtree — a selected block carries its children — and renders as one accent-tinted card per contiguous run, the floating action bar applying class assign/unassign, tags, moves, and confirmed deletes across the set.

**The ghost block** — the original behavior, refined: the page root trails exactly one muted "+ Add block" row as the last sibling of the main level — even on an empty body, in outline and prose; one click creates a real empty block at the end and focuses it; the bullet reads faint, and prose drops it like every prose bullet; in cards mode the affordance is the grid's last cell — a dashed ghost card, "+ Add card", the same click realizing a new card, an empty body included; system sections and property values never trail a ghost — the ghost is document-body chrome, their add flow is the section's own "+"; the focused block view trails the same single ghost as the **last child of the focused block** — the child indent level, never a sibling of it — the same click realizes a real child.

**Prose mode** — a pure view transform: bullets hidden, indents flattened; collapse is honored, not ignored — folded subtrees hide, the chevron start-anchors the row, hover-revealed and persistent at rest while collapsed (owner ruling 2026-10-15), and the fold chords act on the same state; only the indent-line fold gesture stays outline-only.

**The condensed layer** (stretchtext, owner 2026-10-15 — a display layer over the view modes, NOT a mode): under the layer every block in the page body renders its *excerpt* — its content flattened to one line, cut at the first hard break or the 80-char dense-chrome budget, the same derivation that powers breadcrumbs and search rows — whichever layout the body wears; a permanent muted **"…"** (the classic stretchtext mark) rides after the excerpt text, always visible at rest — **and it IS the toggle in both directions** (owner ruling 2026-10-15): tap it to stretch the block in place, and on a stretched block it returns at the **end of the text** (inline after the last word, wherever the text wraps) — tap it again to re-condense; no separate pin or condense buttons. The hidden-links badge rides beside the mark, **revealed with the row** — row hover + focus-within (the resting-rows-stay-clean law: the permanent "…" names the truncation, the controls appear when the row is engaged; it never rides a stretched row — all text is visible, the hidden count is 0); **the row stays editable**: clicking it enters edit on the block's full content (the standard click-to-edit — the excerpt is display chrome, the editor always edits the real content) and blur re-condenses; only the mark pins, and only the mark — or the condense-all reset — un-pins it: editing never pins, blur never unpins, the stretched set is purely the mark-pinned set; **a pinned block reads at a glance**: its "…" toggle becomes a **filled chip** in the app's active-toggle register (the same primary-container fill the focus-mode TopBar button wears — muted mark = closed, filled chip = open); no bullet indicator — the chip is the single cue in every mode; the badge names the mentions hidden past the cut and opens a bounded popup listing those nodes (clicking opens the node — the list is the discovery surface, the pin button is the stretch surface); prose-less blocks (images, queries, code, whiteboards) and one-line blocks never condense; in cards mode the content rows condense as display-only growth — no edit entry; DEVICE-PERSISTED per page (`condensed.<pageId>`) plus a per-page stretched set (`notees.stretched.v1.<pageId>`), all of it view state, never an op; the layer toggle is an app **TopBar button beside the focus-mode switch** and a command-palette action (**Condensed: enter / Condensed: exit**, the focus row's pattern — both act on the active page's per-page pref, so the button follows navigation), with the condense-all reset riding the page's nodeview bar beside the view switcher (owner directive 2026-10-15); the condensed chrome stays visible in focus mode — stretching is the reading act, not metadata chrome ([pages.md](pages.md#focus-mode)); offered on the page body only — embedded feeds, read-only projections, exports, and shares render full content by construction.

**Drag reorder** — dnd-kit, deep-drop to reparent, guard-railed against cycles and CHECK violations; the preview is frozen — NO row moves while dragging, only a highlight line snaps to the nearest valid location by pointer proximity: far from every location no indicator shows; every anchor sits at a **block element's boundary** — a "below"/"child" line always means after THE ENTIRE block (text row, properties, linked references, children), never mid-element at the text row — and one divider hosts **every nesting level** the surrounding tree allows: the boundary before a top-level row is simultaneously "previous sibling of it", "next sibling of the subtree above at its own depth", and "first child of that subtree's last block" — the pointer's **indentation** picks among them (the line's x follows the winning level). The indicator is a straight line repainted in a layer ABOVE the floating drag chip — its left edge starts at the winning level's gutter, so the chip never covers the indentation cue; the dragged block reads faint in place; the preview is a FILLED card with the block's full text — it rides the pointer in free flight, and once a drop target snaps it PARKS just below the indicator line at the winning indentation (snapping between targets with a short transition), a live picture of the document after the drop; a drag reaching the edge of a scrollable view smoothly auto-scrolls it, the indicator tracking the revealed rows; dragging the bullet of a **selected** row moves the whole selection stack — the top-level roots reparent together, internal structure preserved — with the chip reading "N blocks".

**Block moves without dragging** — `Alt+Shift+↑/↓`, one move per press, the caret stays put.

**Global undo/redo** — [undo.md](undo.md).
