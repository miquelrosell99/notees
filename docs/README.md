# Notees documentation

Documentation for people — using the app, and developing or operating it.
Nothing here tracks implementation progress; that record lives in the repo's
internal plan.

## Using Notees

- **[Using Notees](usage.md)** — install, run, and drive the app: the CLI
  tutorial, the web app, the object API reference.
- **[The Notees interaction model](ux.md)** — how it feels: the outliner, the
  views, the sections, the gestures.
- **[Notees philosophy](philosophy.md)** — the ideas under the product, stated
  plainly.

## Developing & operating Notees

The **[developers/](developers/)** runbooks — the workflows that change rarely
and are easy to get wrong (architecture, hacking, deployment, live data
migrations, releases & client lockstep). Start from
[developers/README.md](developers/README.md).

The normative model and wire spec live in
[packages/protocol/SCHEMA.md](../packages/protocol/SCHEMA.md) — the authority
the developer docs summarize.
